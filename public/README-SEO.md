# OG Image untuk SYAMSA

## Ukuran yang Dibutuhkan
- **Dimensi**: 1200 x 630 pixel
- **Format**: JPG atau PNG
- **Nama file**: `og-image.jpg` atau `og-image.png`

## Rekomendasi Desain

### Layout Suggested:
```
┌─────────────────────────────────────────┐
│  Background: Gradient biru gelap (#0C1F3D → #0C4E8C)
│                                         │
│        ┌─────────────────┐              │
│        │   [Logo SYAMSA] │              │
│        └─────────────────┘              │
```

## Tools untuk Membuat OG Image:

1. **Canva** (Gratis) - canva.com
   - Template "Social Media Post" dengan ukuran 1200x630
   - Gunakan brand colors SYAMSA: Biru (#0C4E8C), Gold (#F59E0B)

2. **Figma** (Gratis) - figma.com
   - Frame dengan 1200x630
   - Export as JPG quality 80-90%

3. **Online Converter**
   - Buat SVG lalu konversi: svgtopng.com
   - Atau buat langsung JPG di: photoroom.com, canva.com

## Brand Colors SYAMSA:
- Primary Blue: `#0C4E8C`
- Dark Blue: `#0C1F3D`
- Accent Gold: `#F59E0B`
- Text White: `#FFFFFF`
- Text Gray: `#94A3B8`

## Setelah Jadi:
1. Simpan file sebagai `og-image.jpg`
2. Letakkan di folder `public/`
3. Build: `npm run build`
4. Upload `og-image.jpg` ke GitHub Pages bersamaan dengan `dist/`
